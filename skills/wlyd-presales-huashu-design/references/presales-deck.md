# Huashu Design 方法到售前方案的执行映射

| 方法 | 本插件执行点 | 检查方式 |
| --- | --- | --- |
| 内容先于装饰 | 组稿输出 `label/title/text/emphasis`，每块保留来源 | 事实与引用校验；拒绝无来源数字 |
| 一个视觉方向 | `visualDesign.direction/palette` 由内容选择并保存在 JSON | 同稿重渲染配色不漂移 |
| 层级与阅读起点 | `src/html.js` 区分页标题、卡片主张和说明，长句分组 | 页面截图检查字号、留白和对齐 |
| 内容关系决定页型 | 观点、流程、对应、图表、真实截图分别渲染 | 逐页核对图形与文字是否一致 |
| 真实资产 | 只使用上传的截图和有依据的指标；缺图标明上传目的 | 不把占位或 CSS 示意说成真实产品界面 |
| 五维复核 | 风格一致性、层级、细节、功能性、图形是否增进理解 | 真实浏览器逐页检查，代码测试不能替代视觉评审 |

上游 Skill 的三方向人工选稿、动画、MP4 与可编辑 PPTX 导出不属于本插件自动售前流程。本插件采用内容驱动的自动选型，以满足用户直接生成的交互要求。
