# 可核对的话术指纹（观察版）

版本：`observed-callwan-20261013`。用途是约束售前方案的阅读顺序和表达方式，不提供跨项目可复用的客户事实。

## 依据与把握范围

- 主样本：用户提供的 `CallWan-AI企业增长平台解决方案-集团模板-20260927.html`，共 30 页，可提取正文的页面 27 页。人工核对了目录、挑战、方案机制、平台能力和实施页面。
- 另一份协同工作台 PDF 的可提取正文含“待人工复核”和内部来源路径，不能据此确认是人工定稿，本版没有把它归为人工话术样本。
- 独立话术分析模型本轮超时，未得到经过逐字引文校验的自动报告。因此以下是**一份人工样本的可观察写法**，不是作者思考过程，也不是所有产品通用的确定模板。后续有更多获认可成稿时再增补、版本化复核。

## 可复用的写法

1. 先让新读者知道产品是什么、面向谁、解决哪一段业务问题。增长环境可以在目录中先出现，但封面或开篇仍须有可复述的产品定义。
2. 目录按“环境变化 → 典型挑战 → 总体做法 → 产品能力 → 实施服务 → 公司背景”建立阅读路径。没有对应材料的段落可合并或省略，不固定六章。
3. 问题标题用短标签加具体表现；正文再写信号在哪里断、谁受影响。示例“线索分散：多渠道信号难统一承接”仅用于说明写法，不能套到无关客户。
4. 方案页先说明业务环节如何衔接，再解释产品和平台分别做什么。每个能力回答“谁操作、做什么、留下什么结果”，避免只列产品术语。
5. 页面标题尽量是一句带对象和动作的结论；一页突出一个关系，流程用顺序图，问题与做法用对应图。缺真实界面时在**内部稿**标出应放哪张截图，等待编辑替换。
6. 说清已具备、试点中和实施边界。数字、客户案例、资质和服务承诺只能来自本轮有效证据。

优先级：本轮材料事实与用户已确认口径 > 这些观察规则 > 版式偏好。样本中的产品能力、趋势、数字与客户情况不得迁移为新项目事实。
